# BromoJPG

Landing page untuk BromoJPG — jasa tur Gunung Bromo (sunrise tour, jeep tour, camping).

## Fitur
- Hero dengan booking bar ala referensi
- Galeri perjalanan
- Jadwal & booking paket
- Skema penjemputan
- FAQ
- Floating tombol WhatsApp

## Menjalankan secara lokal
Buka `index.html` langsung di browser, atau jalankan server statis sederhana:

```bash
python -m http.server 8080
```

Lalu akses `http://localhost:8080`.
